# TabPFN-3 Foundation Model for IRIS IntegratedML

> Prior Labs' [TabPFN-3](https://priorlabs.ai/technical-reports/tabpfn-3)
> tabular foundation model exposed as IRIS IntegratedML Custom Models.

## What this demo is

[TabPFN](https://github.com/PriorLabs/TabPFN) (Tabular Prior-data Fitted
Network) is a transformer-based **foundation model for tabular data**. It is
pre-trained once on millions of synthetic tabular tasks and then performs
_in-context learning_ at inference time — no per-dataset gradient training
needed. TabPFN-3, the latest release, extends the recipe to enterprise
scale: up to 1M rows × 200 features (or 1k rows × 20k features), SOTA on
[TabArena](https://tabarena.ai/), many-class classification, text features,
and relational data.

This demo wraps TabPFN-3 in two self-contained `IRISModel` classes — one
classifier, one regressor — so you can call it directly from IRIS SQL:

```sql
CREATE MODEL PatientRiskScreener PREDICTING (needs_followup)
FROM TabPFN.PatientScreening
USING {
    "pathtoclassifiers": "/opt/irisapp/demos/tabpfn_foundation/iris_models/_staging/tabpfn_classifier",
    "iscmodelsdisabled": 1,
    "userparams": {"device": "cpu", "n_estimators": 8}
}
WHERE split = 'train';
TRAIN MODEL PatientRiskScreener;

SELECT patient_id, PREDICT(PatientRiskScreener) AS needs_followup
FROM TabPFN.PatientScreening WHERE split = 'test';
```

## What's in the box

| IRISModel file                          | Wraps                          | Default backend           |
|-----------------------------------------|--------------------------------|---------------------------|
| `iris_models/tabpfn_classifier.py`      | `tabpfn.TabPFNClassifier`      | TabPFN-3 (open weights)   |
| `iris_models/tabpfn_regressor.py`       | `tabpfn.TabPFNRegressor`       | TabPFN-3 (open weights)   |

Both fall back to `sklearn.ensemble.GradientBoostingClassifier` /
`GradientBoostingRegressor` when the `tabpfn` package isn't importable in
the IRIS Python environment, so the demo runs offline with no extra installs.
The active backend is exposed on `IRISModel.backend` (`"tabpfn"` or
`"sklearn"`).

## Sample datasets

Two small synthetic datasets sized for TabPFN's sweet spot (`≤ 10k` rows):

| Dataset                         | Task           | Rows | Features | Target            |
|---------------------------------|----------------|------|----------|-------------------|
| `data/patient_screening.csv`    | Classification | 300  | 11       | `needs_followup`  |
| `data/building_energy.csv`      | Regression     | 300  | 8        | `kwh_day`         |

Both have non-linear interactions baked in (`bmi × glucose` for patients,
`insulation × outdoor_temp` for buildings) so a foundation model has
something to learn beyond a linear baseline.

## Quick start (offline, no IRIS required)

```bash
# Install demo deps (numpy, pandas, scikit-learn, pytest)
make install

# Unit tests — work with or without `tabpfn` installed
pytest demos/tabpfn_foundation/tests/ -v

# End-to-end demo against the sample CSVs
python run_tabpfn_demo.py
```

You'll see two run sections:

1. **Classification** — patient risk screening with AUC, classification
   report, top-5 most-confident high- and low-risk patients.
2. **Regression** — building energy consumption with MAE / RMSE / R² / MAPE
   and the rows with the largest absolute errors.

The runner prints `Active backend: tabpfn` when the real model is loaded
and `Active backend: sklearn` when the fallback is active.

## Enable the real TabPFN-3 backend

In the IRIS container (or your local Python env):

```bash
pip install tabpfn
```

This pulls PyTorch and the open-weights TabPFN-3 checkpoint. On first use
the package prompts you to accept the Prior Labs license at
[ux.priorlabs.ai](https://ux.priorlabs.ai). Set `device="cuda"` in
`userparams` if you have a GPU available.

For larger datasets that exceed the default pre-training guardrails, pass
`"ignore_pretraining_limits": true` in `userparams`.

If you want cloud inference instead of local weights, install
[`tabpfn-client`](https://github.com/PriorLabs/tabpfn-client) — these
`IRISModel` files probe both import paths and pick whichever is present.

## Deploy into IRIS

```bash
# 1. Stage classifier and regressor into their own pathtoclassifiers /
#    pathtoregressors directories.
python demos/tabpfn_foundation/scripts/deploy_models.py

# 2. Create the schema + tables.
iris session iris -U USER < demos/tabpfn_foundation/sql/01_setup_tables.sql

# 3. Load the CSVs into TabPFN.PatientScreening / TabPFN.BuildingEnergy
#    (use the loader tool of your choice — IRIS load utility, dbt, a tiny
#    Python script over JDBC, etc.).

# 4. Train + score the models.
iris session iris -U USER < demos/tabpfn_foundation/sql/02_create_models.sql

# 5. Inspect metrics + hardest cases.
iris session iris -U USER < demos/tabpfn_foundation/sql/03_evaluation.sql
```
